# PHOTO-P01 — 사진이 묻는 하루 형성평가 카드

- 목적: 코드를 만들기 전에 `사진 사이의 질문`이 실제 기억을 꺼내고 결과가 사용자 자신의 글처럼 느껴지는지 확인한다.
- 참여자: 프로젝트 제안자 1명
- 성격: 자기 형성평가. 독립 사용자 효과 검증이 아니다.
- 예상 시간: 10~15분

## 준비물

- 같은 날 촬영한 JPG·PNG 사진 6~10장
- 가능하면 오전부터 밤까지 시간순
- 특별한 사건보다 평범한 하루도 적합

아동, 신분증, 집 주소, 차량번호, 의료정보 등 민감한 내용은 제외하거나 가린다. 현재 대화에서 시험한다면 채팅 서비스의 데이터 처리 조건이 출품 앱의 API 조건과 같다고 가정하지 않는다. 불편하면 실제 사진 대신 공개 가능한 합성·연출 사진을 사용한다.

## 입력 방법

1. 사진을 한 번에 첨부한다.
2. 첨부 과정에서 촬영시각이 사라질 수 있으므로 파일명 또는 메시지에 `01`~`10` 순서만 적는다.
3. 사진 설명, 당시 감정, 함께한 사람은 미리 말하지 않는다. 질문이 사진 밖 정보를 얼마나 잘 꺼내는지 보기 위해서다.
4. 원본 파일은 프로젝트 저장소에 복사하지 않는다.

## 진행 계약

AI는 다음 순서로 진행한다.

1. 사진마다 직접 보이는 사실과 모르는 부분을 분리한다.
2. 전체 사진의 변화나 공백을 근거로 질문 하나를 한다.
3. 참여자 답을 받은 뒤 다음 질문을 한다.
4. 총 3개 질문 뒤 4~7문장 일기를 만든다.
5. 모든 문장 뒤에 `PHOTO-##`, `USER-##` 근거를 표시한다.

AI는 인물의 신원·관계·감정, 장소의 정확한 명칭, 사진 밖 사건을 추측해 확정하지 않는다.

## 참여자에게 보일 시작 문구

> 같은 날의 사진 6~10장을 시간순으로 올려주세요. 사진 설명은 아직 하지 마세요. 제가 먼저 사진에서 확인되는 것과 모르는 것을 나누고, 오늘을 되돌아보는 질문을 하나씩 세 번 드리겠습니다.

## v1 종료 질문 — 역사 기록

일기 생성 후 참여자는 아래 네 항목에 답한다.

1. 세 질문 중 사진만 봤을 때 잊고 있던 기억을 떠올리게 한 질문은 몇 개인가?
2. 사진 설명을 반복했거나 답하기 싫었던 질문은 무엇인가?
3. 근거가 없거나 사실과 다른 문장은 무엇인가?
4. 이 글이 `내 글 같다`는 느낌은 1~5점 중 몇 점인가?

## v1 통과 기준 — 역사 기록

- 새 기억을 떠올리게 한 질문: 1개 이상
- 캡션 반복 질문: 1개 이하
- 근거 없는 사실·감정 문장: 0개
- 문장 근거 표시: 100%
- `내 글 같다`: 4/5 이상

`SRC-087`의 지표 타당성 이의 후 이 문항과 기준은 `DEC-020`으로 대체됐다. 최초 문항을 사후 삭제하지 않기 위해 남긴다.

## v2 종료 질문

1. 세 질문 중 사진만 봤을 때 잊고 있던 기억을 떠올리게 한 질문은 몇 개인가?
2. 사진 설명을 반복했거나 답하기 싫었던 질문은 무엇인가?
3. 내가 말하지 않았는데 AI가 추가한 구체적인 내용은 어느 문장인가?
4. 이 기록에 내가 중요하게 생각한 순간과 그 이유가 담겼는가? `1~5`
5. 이 기록을 나중에 다시 보기 위해 저장하고 싶은가? `예/아니요`
6. `내 말투 보존`을 선택한 경우에만 표현이 내 말투와 가까운가? `1~5`

## v2 통과 기준

- 새 기억을 떠올리게 한 질문: 1개 이상
- 캡션 반복 질문: 1개 이하
- 사용자가 말하지 않은 구체적인 내용: 0개
- 문장 근거 표시: 100%
- 중요한 순간과 이유 반영: 4/5 이상
- 저장 의향: 예

말투 유사성은 선택 보조 지표이며 전체 통과를 결정하지 않는다.

## 기록 원칙

- 프로젝트에는 원본 사진과 대화 원문을 기본 저장하지 않는다.
- 저장하는 것은 사용자가 허용한 익명화 지표, 실패 유형, 질문 설계 수정 이유뿐이다.
- 사진·답변 예시를 제출물에 사용할 때는 별도 동의를 받는다.
- 통과하지 못해도 점수를 좋게 보이도록 질문이나 기준을 사후 변경하지 않는다. 변경이 필요하면 새 버전과 이유를 남긴다.
