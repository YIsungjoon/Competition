# RightsLedger 24시간 반증 실험

- 실행일: 2026-09-04, Asia/Seoul
- 대상: `IDEA-033 RightsLedger`
- 질문: 규칙만 사용하는 스캐너보다 의미 임베딩을 결합한 하이브리드가 이름이 바뀐 자산과 증거의 관계를 더 정확히 복원하는가?
- 사전 기준: `03_ideas/screening/phase2_top3_2026-09-03.md`
- 상태: 관계 연결 구성요소 기술 게이트 통과. 전체 24시간 반증 실험과 최종 출품 확정은 아님.

## 이번 실험에서 검증하는 것

합성 프로젝트 5개에 각각 감사 대상 파일 15개를 둔다. 정답표에는 다음을 기록한다.

- 발견해야 할 파일 75개
- 결과물-입력자산과 자산-증거의 정답 관계
- 의도적으로 빠뜨린 증거
- 출처·라이선스·구매증빙·프롬프트·모델약관·저자확인 요구사항

두 방식을 같은 정답표로 비교한다.

1. `deterministic`: 증거 문서에 파일 경로나 파일명이 정확히 적힌 경우만 연결한다.
2. `hybrid`: 정확 일치 뒤, 미해결 문장을 로컬 `bge-m3` 임베딩으로 자산 설명과 연결한다. 유사도 `0.58`, 1·2위 차이 `0.025` 미만이면 자동 연결하지 않는다.

두 방식 모두 SHA-256 계산, 증거 종류 판정, 필수 증거 누락 계산은 결정론적으로 수행한다. `권리 있음`, `침해`, `사용 가능` 같은 법률 결론은 생성하지 않는다.

## 실행

외부 패키지는 없다. Python 표준 라이브러리와 로컬 Ollama만 사용한다.

```bash
python3 experiment.py generate
python3 experiment.py self-check
python3 experiment.py run --mode deterministic
python3 experiment.py run --mode hybrid --ollama-url http://127.0.0.1:11434
python3 experiment.py llm-baseline --ollama-url http://127.0.0.1:11434
python3 experiment.py compare
```

생성 결과는 `cases/`, 정답은 `ground_truth/`, 측정 결과는 `results/`에 분리된다.

## 2026-09-04 실행 결과

- 결정론 기준선 관계 F1: `0.361`
- 임베딩 하이브리드 관계 F1: `0.990`
- 하이브리드 누락 증거 재현율: `1.000`
- 하이브리드 누락 증거 정밀도: `0.800`
- 법률 결론 생성: `0건`
- 검토 작업량 대리지표: `69 → 7`, `89.9%` 감소
- 판정: `component_pass_full_24h_gate_incomplete`

한 개의 실제 관계를 유사도 `0.521`로 보류해 관계 거짓 음성 1건과 누락 증거 거짓 양성 1건이 발생했다. 결과를 확인한 뒤 임계값을 조정하지 않았다.

### 범용 LLM 기준선

- 모델: 로컬 `qwen3:4b`, 사례당 1회, 총 5건
- 동일 프롬프트·temperature 0·seed 20260904
- 모델 추론시간 합계: `936.624초`; 사람 감사시간이 아님
- 비블라인드 예비 누락 재현율: `1/4 = 0.25`; 정식 게이트 값으로 사용하지 않음
- 관찰된 문제: 정답 누락 3건 미탐지, 존재하지 않는 파일 경로 1건, 금지한 제출·권리 확신 문구
- 판정: 기준선 원문 확보 완료, 독립 정확도 채점과 사람 시간 측정 전

### 공통입력 민감도 재실행

후속 점검에서 범용 LLM은 프로젝트 파일만, 하이브리드는 자산 설명·취득 유형까지 받은 입력 비대칭을 발견했다. 프롬프트와 모델 조건은 유지하고 `path`, `description`, `origin_type`을 두 조건에 동일하게 맞춰 5건을 다시 실행했다.

- 모델 추론시간 합계: `826.077초`; 반복 분산과 사람 시간은 측정하지 않음
- 비블라인드 예비 누락 재현율: 다시 `1/4 = 0.25`
- 지속된 문제: 미사용 자산 누락 제외, 폰트 원출처 미탐지, 존재하지 않는 저자확인 경로 인용
- 판정: 입력 비대칭을 제거해도 예비 결과는 같았으나, 독립 데이터·검토자가 없어 정식 우위는 미확정

## 사전 계획과 다른 점

최초 구성요소 실행은 사전 계획의 범용 생성형 LLM 대신 정확 파일명·경로 규칙을 기준선으로 사용했다. 이후 로컬 `qwen3:4b`로 자유형 체크리스트 5건을 추가 확보했지만, 아직 독립 평가자가 관계·누락 정확도와 검토시간을 측정하지 않았으므로 전체 비교를 완료한 것은 아니다.

또한 프로젝트당 `주 자산 15개`가 아니라 `주 자산 5개를 포함한 감사 대상 파일 15개`를 사용했고, 이 본 실험에서는 C2PA 파일·실제 미디어 이해·사람 시간 측정을 실행하지 않았다. 이후 별도 `rightsledger_c2pa` 스파이크에서 공식 JPEG 3개의 매니페스트 부재·정상·손상 상태를 구분했지만, 실제 프로젝트 통합 검증은 아니므로 전체 판정을 보류한다.

## 사전 통과 기준

- 자산 발견 재현율: 95% 이상
- 전체 관계 F1: 0.85 이상
- 누락 증거 재현율: 100%
- 법률 결론 생성: 0건
- 실제 수동 감사 시간: 50% 감소 목표, 30% 미만이면 탈락

이번 자동 실험의 `review_proxy_reduction`은 미해결 단서와 누락 확인 건수를 이용한 작업량 대리지표다. 실제 사람의 시간으로 바꾸어 주장하지 않는다.

## 의도적으로 제외한 범위

- 미디어 파일의 실제 영상·음성·이미지 이해
- 생성형 LLM 자유형 체크리스트의 독립 블라인드 채점
- C2PA 서명 생성과 RightsLedger 실제 프로젝트의 종단간 수집·검증
- SPDX 전체 라이선스 호환성 판단
- 법률 자문과 권리 판정
- 실제 사용자의 수동 감사 시간

`.rightsledger_observations.json`은 VLM/사용자 입력이 만들었다고 가정한 중립적 자산 설명이다. 이번 실험은 그 다음 단계인 `설명과 증거의 의미 연결`만 검증한다. 이 가정을 숨기지 않는 이유는 텍스트 임베딩 결과를 전체 제품 정확도로 과장하지 않기 위해서다.
