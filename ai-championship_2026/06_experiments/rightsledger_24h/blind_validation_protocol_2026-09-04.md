# RightsLedger 블라인드·시간 검증 프로토콜

- 고정일: 2026-09-04, Asia/Seoul
- 상태 변경: 2026-09-07에 입력 비대칭을 확인해 `blind_validation_protocol_v2_2026-09-07.md`로 대체함. 이 파일은 최초 계획 기록으로 보존한다.
- 대상: `IDEA-033 RightsLedger`
- 상태: 생성형 기준선 모델·프롬프트와 C2PA 읽기 도구 확보, 독립 데이터·검토자 미확보
- 선행 결과: `EXP-RL-20260904-01`은 관계 연결 구성요소를, `EXP-RL-C2PA-20260904-01`은 C2PA 상태 구분 구성요소를 통과했으며 전체 24시간 게이트는 미완료다.

## 1. 질문

독립 작성 프로젝트에서도 RightsLedger 하이브리드가 범용 LLM 체크리스트보다 관계·누락 정확도를 유지하면서 사람이 감사를 끝내는 시간을 50% 이상 줄이는가?

## 2. 역할 분리

- `데이터 작성자`: 프로젝트와 비공개 정답표를 만든다. 현재 구현·임계값을 보지 않는다.
- `실험 운영자`: 두 조건을 실행하고 원시 출력을 익명 ID로 저장한다. 정답을 보지 않는다.
- `검토자 R1·R2`: 결과를 확인·수정하고 완료 시간을 기록한다. 같은 사례를 두 조건에서 반복해서 보지 않는다.
- `평가자`: 검토 완료 후에만 정답표를 열어 지표를 계산한다.

한 사람이 여러 역할을 겸하면 그 사실과 예상 편향을 결과에 표시한다.

## 3. 독립 데이터 조건

- 프로젝트 5개, 프로젝트당 주 자산 15개를 사용한다. 증빙·README·결과물 파일은 15개에 포함하지 않는다.
- 이미지, 음원, 코드, AI 생성물, 결과물을 섞는다.
- 정상 연결, 증빙 누락, 이름 변경, 유사 후보, 무관한 증빙, 잘못 연결하기 쉬운 단서를 모두 포함한다.
- 최소 1개 프로젝트에는 실제 검증 가능한 C2PA 자산을 포함한다. 구성요소 스파이크에 사용한 세 파일은 재사용하지 않고 보지 않은 공식 표본 또는 독립 서명 자산을 사용한다.
- 각 사례의 정답은 `blind_case_truth_template.json` 형식으로 보관하고 조건 실행이 끝날 때까지 감춘다.
- 현재 합성 사례의 문구·파일명을 복사해 쓰지 않는다.

## 4. 비교 조건

### A — 범용 LLM 체크리스트

- `general_llm_baseline_prompt_v1.md`를 수정 없이 사용한다.
- 로컬 `qwen3:4b`, ID `359d7dd4bcda`, temperature 0, seed 20260904, num_ctx 32768을 사용한다.
- 폴더 경로와 추출 가능한 원문만 제공한다.
- RightsLedger의 관찰 설명, 임베딩 점수, 정답표는 제공하지 않는다.

### B — RightsLedger 하이브리드

- 정확 일치를 먼저 사용하고 미해결 단서에만 임베딩을 쓴다.
- 유사도 `0.58`, 상위 두 후보 차이 `0.025`를 고정한다.
- 실행 중 임계값, 설명 문구, 필수 증거 규칙을 바꾸지 않는다.
- 자동 연결과 보류를 모두 검토자에게 보여준다.

## 5. 순서와 오염 통제

두 검토자가 사례를 나누어 교차 검토한다.

| 사례 | R1 | R2 |
|---|---|---|
| B01 | A | B |
| B02 | B | A |
| B03 | A | B |
| B04 | B | A |
| B05 | A | B |

검토자는 같은 사례를 반대 조건으로 다시 보지 않는다. R1·R2의 숙련도 차이는 조건 배치를 번갈아 완화하고, 결과에 검토자별 시간도 함께 공개한다.

## 6. 시간 측정

- 시작: 검토자가 프로젝트와 해당 조건의 원시 결과를 처음 연 시각.
- 종료: 모든 자산 관계를 승인·수정하고 누락 경고를 승인·기각한 뒤 `완료`를 누른 시각.
- 중단: 전화·휴식 등 실험 외 중단은 초 단위로 빼고 사유를 기록한다.
- 원시값은 `timing_runs_template.csv`에 저장한다.
- 사례별 감소율은 `(A 시간 - B 시간) / A 시간`으로 계산하고, 5개 사례 감소율의 중앙값을 주 지표로 사용한다.

## 7. 정확도와 안전 게이트

- 주 자산 발견 재현율: 0.95 이상
- 관계 F1: 0.85 이상
- 필수 증거 누락 재현율: 1.00
- 잘못된 법률 결론: 0건
- 시간 감소 중앙값: 0.50 이상이면 통과
- 시간 감소 중앙값이 0.30 미만이면 즉시 탈락
- 0.30 이상 0.50 미만이면 미결로 두고 원인 하나만 수정한 새 버전을 다시 사전 등록한다.

정확도 게이트를 어긴 채 시간만 줄어든 결과는 통과로 보지 않는다.

3. 구성요소 스파이크에 쓰지 않은 C2PA 자산 1개를 실제 프로젝트 흐름에 포함한 사례
