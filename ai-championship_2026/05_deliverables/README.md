# 최종 산출물

이 폴더에는 대회에 제출하거나 데모데이에 사용할 준비가 끝난 산출물만 둔다.

## 진입 조건

- 관련 결정 ID가 있다.
- 사실과 수치가 출처 ID로 연결된다.
- 배포 URL 또는 재현 절차가 있다.
- 실제 화면과 핵심 사용자 흐름을 검증했다.
- 알려진 제한과 안전장치를 명시했다.

`IDEA-033 RightsLedger`의 로컬 MVP가 `rightsledger_mvp/`에 있으나, 실제 화면 검토 후 제출 개발 대상에서 동결했다. 기술 검증과 설계 학습은 보존하되 최종 출품본으로 표시하지 않는다. 현재 출품 개발 1순위는 `IDEA-051 사진이 묻는 하루`이며 `photo_reflection_mvp/MVP_CONTRACT.md`와 `DEC-017`, `DEC-018`의 검증·배포 게이트를 따른다. 아직 실제 사진 모델 호출과 공개 URL을 통과하지 않았으므로 이 폴더의 계약서는 제출 완료물이 아니다.
