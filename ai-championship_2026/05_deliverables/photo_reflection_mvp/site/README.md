# 사진이 묻는 하루

사진을 자동으로 설명하는 대신, 사진만으로 알 수 없는 기억을 질문하고 사용자가 확인한 말만 짧은 기록으로 엮는 AI 기억 인터뷰입니다.

## 핵심 흐름

1. JPG·PNG·WEBP 사진 3~8장을 고릅니다.
2. 브라우저가 사진을 1280px 이하 JPEG로 다시 인코딩해 크기를 줄이고 메타데이터를 제거합니다.
3. GPT-5.6 Luna가 사진에서 직접 본 것과 아직 모르는 것을 분리하고 질문 세 개를 만듭니다.
4. 사용자가 답하거나 건너뜁니다.
5. AI가 제목과 4~7문장을 만들고, 서버가 각 문장의 `PHOTO`, `USER`, `TIME`, `AI_STYLE` 근거를 검사합니다.
6. 근거가 없거나 허용되지 않은 근거 ID가 있는 결과는 화면에 표시하지 않습니다.

## 로컬 실행

```bash
npm install
cp .env.example .env.local
# .env.local에 서버용 OPENAI_API_KEY 입력
npm run dev
```

검증:

```bash
npm run lint
npm test
npm run build
```

## 데이터 경계

- 원본 파일은 서버나 데이터베이스에 저장하지 않습니다.
- 축소·재인코딩한 사본만 AI 분석 요청에 포함합니다.
- OpenAI Responses API 요청은 `store: false`로 보냅니다.
- 분석 버튼 전에 외부 API 전송과 안전 로그의 최대 30일 유지 가능성을 고지하고 동의를 받습니다.
- API 키는 서버 환경변수에서만 읽습니다.
- 샘플 결과는 제품 화면 확인용 고정 예시이며 실제 AI 분석으로 표시하지 않습니다.
