## 1. 소비·계약·구매

### IDEA-021 — ReturnRight: 환불 가능성보다 환불 증거 준비

- 문제 기능: 검증(PF-02), 구조화(PF-04), 실행(PF-10)
- 문제: 주문내역, 약관, 사진, 상담 기록이 흩어져 환불 요청의 근거와 누락 항목을 찾기 어렵다.
- AI 역할: 자료에서 상품, 약속, 하자, 날짜, 판매자 답변을 추출해 주장과 증거를 연결한다.
- 검증: 환불 규정의 원문 위치, 구매일, 사진 촬영일, 사용자의 최종 확인.
- 데모: 주문서·하자 사진·채팅 입력 → 증거 타임라인 → 판매자에게 보낼 요청서와 누락 증거.
- 근거/위험: `SRC-010`; `환불`은 게임 사건에 오염됐으므로 일반 소비자 수요는 별도 검증이 필요하다.

### IDEA-022 — SubscriptionExit: 구독 탈출 지도

- 문제 기능: 감지(PF-01), 번역(PF-03), 실행(PF-10)
- 문제: 사용자는 이메일·영수증·카드 내역에 흩어진 구독과 해지 조건을 놓친다.
- AI 역할: 사용자가 제공한 알림에서 반복 결제 후보, 무료체험 종료, 해지 경로를 구조화한다.
- 검증: 금액·결제일 원문 대조, 사용자의 서비스 소유 확인, 실제 해지는 사용자 승인 후 공식 페이지에서만 수행.
- 데모: 합성 이메일과 영수증 → 구독 후보 지도 → 예상 다음 결제와 해지 체크리스트.
- 근거/위험: `SRC-010`; AI 서비스 구독 취소 관련 급등 검색. 금융·이메일 데이터 보안이 핵심이다.

### IDEA-023 — ReviewProof: 리뷰에서 주장과 근거 분리

- 문제 기능: 검증(PF-02), 구조화(PF-04)
- 문제: 사용자는 수백 개 리뷰에서 반복되는 실제 결함과 홍보성 표현을 구분하기 어렵다.
- AI 역할: 리뷰의 구체적 사용조건, 장단점, 반복 문구, 상충 주장을 묶어 증거 지도를 만든다.
- 검증: 모든 요약을 원문 리뷰에 연결하고 조작을 단정하지 않고 이상 신호만 표시한다.
- 데모: 상품 리뷰 묶음 → 조건별 장단점 → 서로 충돌하는 주장과 확인 질문.
- 근거/위험: `SRC-010`에서 직접 수요 신호는 약했다. 리뷰 플랫폼 정책과 평가 데이터 검증이 필요하다.

## 2. 이동·여행·공간

### IDEA-024 — DisruptionRescue: 여행 계획 자동 복구

- 문제 기능: 조정(PF-05), 개인화(PF-06), 실행(PF-10)
- 문제: 항공편·숙소·공연 일정 중 하나가 바뀌면 사용자가 전체 예약과 이동 계획을 다시 맞춰야 한다.
- AI 역할: 예약 문서와 변경 알림을 읽고 영향을 받는 연결 일정을 찾아 대안을 생성한다.
- 검증: 실시간 운항·가격·취소 규정은 공식 API나 링크에서 확인하고 예약은 사용자가 승인한다.
- 데모: 지연 문자 입력 → 영향받는 일정 표시 → 비용·시간별 대안 3개와 문의 초안.
- 근거/위험: `SRC-015`; 항공편 지연 자체의 상대지수는 낮아 실제 사용자 인터뷰가 필요하다.

### IDEA-025 — SignLens: 낯선 주차·교통 표지 해석

- 문제 기능: 감지(PF-01), 번역(PF-03), 개인화(PF-06)
- 문제: 운전자는 복합 표지판과 시간·차종·요일 예외를 현장에서 빠르게 해석하기 어렵다.
- AI 역할: 사진에서 표지 요소를 읽고 현재 시각·차량 조건에 맞는 의미를 설명한다.
- 검증: 공식 도로·주차 규칙, 위치, 시각을 별도 필드로 확인한다.
- 데모: 복합 표지 사진 → 적용 조건 하이라이트 → 지금 가능한 행동과 불확실성 표시.
- 근거/위험: `SRC-015`의 `주차` 값은 중의어 오염으로 사용하지 않는다. 실제 표지 데이터와 법적 책임 검토가 필요하다.

### IDEA-026 — AccessTrip: 이동 제약을 반영한 여행 리허설

- 문제 기능: 개인화(PF-06), 시뮬레이션(PF-07), 조정(PF-05)
- 문제: 휠체어, 시각·청각 민감도, 유아 동반 같은 조건은 일반 여행 일정표에 충분히 반영되지 않는다.
- AI 역할: 사용자의 제약과 장소 설명을 연결해 이동 병목과 사전 질문을 찾는다.
- 검증: 엘리베이터·경사로·운영시간은 장소 공식 정보와 사용자 제보 시점을 분리한다.
- 데모: 사용자 조건과 일정 입력 → 구간별 위험 → 시설에 확인할 질문과 대체 경로.
- 근거/위험: Trends 직접 근거가 약하다. 접근성 당사자 검증 없이는 설계하지 않는다.

## 3. 가족·육아·관계

- AI 역할: 안내문에서 자녀, 날짜, 준비물, 비용, 회신 항목을 추출해 가족 공동 체크리스트로 만든다.
- 검증: 날짜·금액·준비물을 원문과 대조하고 보호자가 승인한다.
- 데모: 알림장 사진 3장 → 자녀별 일정과 준비물 → 공동 확인 화면.
- 근거/위험: `SRC-012`; 검색 상대지수는 낮지만 검색하지 않고 앱 안에서 겪는 문제일 수 있다.

### IDEA-028 — CoParent Handoff: 공동양육 인수인계

- 문제 기능: 구조화(PF-04), 조정(PF-05), 기억(PF-08)

- AI 역할: 선택된 메시지와 음성 메모에서 아이 중심의 사실·요청·미확정 항목을 분리한다.
- 검증: 원문 링크, 작성자, 시간, 양쪽 보호자의 승인.
- 데모: 익명화된 대화 → 인수인계 카드 → 충돌 없는 확인 질문.
- 근거/위험: `SRC-012`의 육아·아이돌봄 신호. 가족 갈등과 아동 정보의 높은 민감도가 위험이다.

### IDEA-029 — FamilyTalk Rehearsal: 어려운 가족 대화 연습

- 문제 기능: 시뮬레이션(PF-07), 개인화(PF-06)

- AI 역할: 사용자의 목표와 관계 맥락에 따라 다양한 반응을 시뮬레이션하고 공격적·회피적 표현을 피드백한다.
- 검증: 특정 심리 진단을 하지 않고 사용자가 정한 대화 목표와 금지 표현만 평가한다.
- 데모: 상황 선택 → 2분 역할극 → 발언별 영향과 더 나은 재시도.
- 근거/위험: Trends 직접 근거 없음. 상담 대체로 오인되지 않도록 범위를 제한해야 한다.

## 4. 반려동물

- AI 역할: 사용자가 촬영한 영상·사진·메모에서 변화 후보를 시간순으로 정리하고 추가 관찰 질문을 만든다.
- 검증: 영상 원본과 시간, 보호자가 확인한 증상만 표시하고 진단은 하지 않는다.
- 데모: 5일치 합성 기록 → 변화 그래프 → 진료실 전달용 1페이지 요약.
- 근거/위험: `SRC-011`; 동물병원 검색은 게임 오염이 있으므로 보호자 인터뷰가 필요하다.

### IDEA-031 — LostPet Pack: 실종 반려동물 수색 자료 생성

- AI 역할: 사진에서 식별 가능한 특징을 설명하고 목격 메시지를 지도·시간순으로 정리한다.
- 검증: 위치·시간은 제보 원문과 사용자 확인을 거치며 얼굴·주소 등 개인정보를 자동 마스킹한다.
- 데모: 반려동물 사진과 제보 4건 → 전단·검색 타임라인·다음 수색 구역.
- 근거/위험: `SRC-011`의 유기동물·입양 신호는 인접 근거일 뿐 실종 수요를 직접 증명하지 않는다.

- 검증: 모든 문장을 원본 구간에 연결하고 외부 사실 검증은 별도 상태로 표시한다.

### IDEA-035 — OralHistory Studio: 가족·지역의 구술 기억 보존

- AI 역할: 방언 음성에서 인물·장소·사건을 추출하고 사진과 연결해 검토 가능한 이야기 지도를 만든다.
- 검증: 원음 보존, 화자 승인, 불확실한 고유명사 표시, 공개 범위 통제.
- 데모: 3분 인터뷰와 사진 → 타임라인·지도·짧은 오디오 이야기.

## 6. 접근성·디지털 소외

- 문제: 디지털 취약 사용자는 뒤에 줄이 있는 실제 매장에서 처음 화면을 익혀야 한다.
- AI 역할: 사용자의 말로 된 목표를 단계별 화면 연습으로 바꾸고 막히는 지점을 다른 표현으로 설명한다.

## 확장 결과의 의미

신규 후보는 특정 산업의 전문성을 우선하지 않는다. 같은 AI 기술이라도 사용자가 가치를 다르게 설계했다.

- 단순 요약 대신 원문과 연결된 행동 변환
- 단순 추천 대신 자격·제약을 검증한 매칭
- 단순 탐지 점수 대신 증거와 다음 확인 절차
- 단순 생성 대신 결정 이유와 출처의 장기 추적
- 자동 실행보다 사용자 승인과 안전한 완료

다음 단계에서는 기존 20개와 신규 30개를 합쳐 문제 기능 분포를 점검하고, 도메인이 아닌 평가 기준에 따라 10~12개만 2차 조사 대상으로 선정한다.
