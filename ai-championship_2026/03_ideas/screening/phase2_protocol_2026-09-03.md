## 1. 공식 대회 조건에서 역산한 기준

`FACT` 원티드는 예선에서 기획력·실현 가능성·확장성·AI 활용 적절성을, 본선에서 기획력·확장성·기술력·발표 전달력을 본다. 아이디어 설명만이 아니라 실제 작동하고 심사 기간에 접속 가능한 배포 링크가 필요하다. 과제 제출 마감은 2026-09-20 23:59:59이다. `[SRC-046]`

따라서 1차의 발산용 점수보다 경쟁 공백, 평가 데이터, 기술 증거의 비중을 높였다. 온라인 투표 매력은 별도 가산점으로 두지 않고 `대회 적합성` 안에서만 제한적으로 본다.

## 2. 모든 후보에 적용한 공통 가정

- 오늘 이후 17일 안에 웹 MVP 한 흐름을 배포한다.
- 1인 또는 소규모 팀이며 독점 데이터, 기존 고객군, 기업 제휴는 없다고 가정한다.
- 호스팅된 멀티모달 모델 API, OCR, 공개 데이터·문서는 사용할 수 있다.
- 입력 자료는 합성 자료, 공개 라이선스 자료 또는 명시적 동의를 받은 자료만 사용한다.
- 사용자 제안 여부, 익숙한 도메인, 개인적 선호에는 점수 보너스를 주지 않는다.
- 제품을 직접 사용하지 못한 경우 공개 기능 설명을 `기능 존재`의 근거로만 쓰며, 품질 우열은 단정하지 않는다.
- 외부 제품을 찾지 못한 것은 `경쟁 제품이 없다`는 뜻이 아니다. 이번 조사 범위에서 직접 대체재를 발견하지 못했다는 뜻이다.

## 4. 탈락 게이트

| 코드 | 질문 | 탈락 조건 |
|---|---|---|
| K1 직접 중복 | 현재 제품이 핵심 약속을 이미 제공하는가? | 같은 입력·결과가 존재하고, 남은 차이를 숫자로 시험할 수 없음 |
| K2 범용 모델 대체 | 범용 멀티모달 채팅 한 번으로 거의 같은 결과가 나오는가? | 구조화·검증·상태 유지가 기준선보다 유의미하게 낫지 않음 |
| K3 평가 불가 | 합법적인 입력과 정답을 구할 수 있는가? | 24시간 안에 최소 평가 세트를 설계할 수 없음 |
| K4 피해 통제 | 틀린 결과의 피해를 제한할 수 있는가? | 출처·사용자 승인·기계적 검증·거부 응답으로도 통제할 수 없음 |
| K5 사용자 접근 | 핵심 당사자에게 시험할 수 있는가? | 제출 전 필요한 당사자 테스트를 현실적으로 수행할 수 없음 |

`통과 조건부`는 게이트 위험이 있지만 24시간 반증 실험으로 판정할 수 있다는 뜻이다. `탈락`은 아이디어가 나쁘다는 뜻이 아니라 이번 대회 일정과 현재 자원에서 우위를 증명하기 어렵다는 뜻이다.

## 5. 증거 등급

- A: 공식 문제 자료, 현행 대체재, 합법적 평가 입력, 실제 사용자 결과가 모두 있음
- B: 공식 문제 자료와 대체재는 확인했으나 동일 입력 비교나 사용자 실험 전임
- C: 대체재 또는 개념 근거는 있으나 문제 빈도·사용자·평가 입력 중 하나 이상이 약함

이번 단계에서 A를 받은 후보는 없다. 실제 제품 비교와 사용자 실험을 아직 하지 않았기 때문이다.
