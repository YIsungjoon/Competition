## 1순위 — IDEA-033 RightsLedger

### 제출용 한 문장

> AI와 여러 도구로 만든 프로젝트 폴더를 넣으면, 모든 자산의 출처·라이선스·생성 이력을 연결하고 빠진 증거만 질문해 제출 가능한 출처 장부를 만든다.

### 왜 지금 1순위인가

- 대회 FAQ 자체가 오픈소스·외부 API·생성형 AI의 라이선스와 이용조건 준수를 요구한다. `[SRC-046]`
- 한국저작권위원회가 2026년 AI 저작권 안내서 4종을 묶어 제공할 만큼 현재성이 있다. `[SRC-066]`
- C2PA를 경쟁자로 피하지 않고 파일 단위 검증 기반으로 사용한다. `[SRC-064]`, `[SRC-065]`
- 모델의 추출 능력과 SHA-256·SPDX·C2PA 검증을 한 화면에서 함께 보여줄 수 있어 `AI가 아니어도 되는 서비스` 비판에 답하기 쉽다.
- 합성 프로젝트로 정답을 만들 수 있어 외부 제휴나 민감 개인정보가 필요 없다.

### 3분 데모

1. 이미지·음원·코드·AI 결과물이 섞인 지저분한 ZIP을 올린다.
2. AI가 결과물-입력자산-도구 관계 후보를 그래프로 만든다.
3. 규칙 엔진이 해시, SPDX, C2PA, 라이선스 원문을 검증한다.
4. `음원 구매증빙 없음`, `AI 모델 이용조건 캡처 없음`, `출처 URL과 파일 불일치` 세 가지를 보여준다.
5. 사용자가 한 질문에 답하거나 증빙을 추가한다.
6. `PROVENANCE.json`과 사람이 읽는 제출용 리포트를 내보낸다.

### 반드시 지킬 제품 경계

- `사용 가능/침해`를 판정하지 않는다.
- `증거 있음/없음/불일치/확인 필요`만 표시한다.
- C2PA가 없다고 가짜 또는 무권리라고 말하지 않는다.
- 업로드 ZIP은 분석 후 즉시 삭제하고 데모는 합성 자산으로 구성한다.
- 블록체인, 자동 계약, 자동 구매, 전 포맷 지원은 만들지 않는다.

### 24시간 반증 실험

- 입력: 자산 15개씩 든 합성 프로젝트 5개.
- 정답: 파일 해시, 원출처, 라이선스 유형, 결과물 관계, 고의 누락 목록.
- 기준선: README와 파일을 같은 범용 LLM에 주고 자유형 체크리스트를 요청한다.
- 통과: 자산 재현율 95%, 관계 F1 0.85, 누락 증거 재현율 100%, 잘못된 법률 결론 0건, 수동 감사 시간 50% 감소.
- 즉시 탈락: 누락 재현율이 90% 미만이거나 일반 체크리스트 대비 시간이 30% 이상 줄지 않음.

### 17일 MVP

- 지원: ZIP, PNG/JPG, MP3/WAV, 소스코드·README, LICENSE/TXT/PDF, C2PA가 있는 미디어.
- 핵심 객체: `project`, `output`, `asset`, `tool/model`, `license_evidence`, `relationship`, `verification`.
- 핵심 화면: 업로드 → 자산 인벤토리 → 관계 확인 → 누락 큐 → 내보내기.
- 데모용 확장: 해커톤 제출 체크와 콘텐츠 납품 체크 두 프로필만 둔다.

## 2순위 — IDEA-051 사진이 묻는 하루

### 제출용 한 문장

> 하루 사진을 시간순으로 보여주는 대신, AI가 사진 사이의 기억 공백을 질문하고 사용자가 확인한 말만 엮어 `내가 쓴 것 같은 일기`를 만든다.

### 왜 여전히 상위인가

- Day One과 Memex가 이미 사진·AI 일기를 제공하므로 시장 부재를 주장할 수 없다. `[SRC-028]`, `[SRC-029]`, `[SRC-062]`
- 그 대신 결과를 `잘 쓴 글`이 아니라 `기억을 더 꺼냈는가`, `내 글 같은가`, `근거 없는 문장이 없는가`로 측정할 수 있다.
- 사진 컬렉션의 정보 분산과 능동적 질문의 필요성은 Memory Reviver 연구와도 접점이 있다. `[SRC-063]`
- 평가 입력을 사용자의 사진 또는 명시적으로 동의받은 사진으로 바로 확보할 수 있다.

### 3분 데모

1. 오전부터 밤까지 사진 8장을 한 번에 올린다.
2. EXIF와 시각 맥락으로 `출근길`, `점심`, `귀가 후` 장면을 묶는다.
3. AI가 `누구와 먹었나요?`가 아니라 `점심과 저녁 사이에 기분이 달라진 계기가 있었나요?`처럼 사진 사이의 공백을 질문한다.
4. 사용자가 음성으로 짧게 답한다.
5. 완성 일기의 각 문장을 누르면 근거 사진·답변·AI 연결문이 보인다.
6. 사용자가 문장을 고치고 내보내거나 원본과 결과를 모두 삭제한다.

### 반드시 지킬 제품 경계

- 사진만 보고 감정·관계·사건을 단정하지 않는다.
- 질문은 최대 5개, 전체 완료 목표는 8분 이하다.
- 일기 모든 문장에 출처 상태를 둔다.
- 얼굴 인식으로 사람을 자동 식별하지 않는다.
- 장기 심리진단, 감정 점수, 가족 공유는 MVP에서 제외한다.

### 24시간 반증 실험

- 입력: 동의받은 5명의 하루 사진 각 8장.
- 기준선: Day One, 같은 멀티모달 모델의 `오늘 일기 써줘` 프롬프트.
- 블라인드 평가: 사실 정확성, 사진 밖 기억 회수, 내 글 같다, 다시 읽고 싶다, 소요시간.
- 통과: 근거 없는 구체문장 5% 이하, 근거표시 100%, 질문의 60%가 사진 밖 정보를 추가, 소유감이 최강 기준선보다 1.0/5 이상 높음.
- 즉시 탈락: 소유감 차이 0.5 미만, 질문이 캡션을 반복, 완료 중앙값 8분 초과.

### 17일 MVP

- 입력: 하루 사진 6~12장, 선택적 음성 답변.
- 핵심 객체: `photo`, `scene`, `memory_gap`, `question`, `answer`, `sentence`, `source_link`.
- 핵심 화면: 사진 묶음 → 장면 타임라인 → 회고 대화 → 문장 근거 → 수정·내보내기·삭제.
- 확장성은 여행·육아·가족사가 아니라, 먼저 `하루 회고 완료율`로 증명한다.

## 3순위 — IDEA-050 ProjectRescue

### 제출용 한 문장

> 설명서와 중단된 작업 사진을 넣으면 AI가 현재 단계를 추측해 확인 질문을 하고, 원문에 묶인 다음 한 단계만 보여준다.

### 왜 와일드카드로 남겼나

- Crafty AI와 Brickit은 재료·부품에서 새 제작 아이디어와 단계를 제공한다. `[SRC-060]`, `[SRC-061]`
- 이번 조사에서는 사용자가 이미 선택한 설명서와 중단 상태를 다시 맞추는 흐름을 직접 확인하지 못했다. 다만 경쟁 부재를 뜻하지 않는다.
- 문제의 절실성·시장 근거는 약하지만 `중단된 실물 → 정확한 다음 행동`의 전후가 매우 시각적이다.
- 범용 VLM과 차이가 없으면 하루 만에 버릴 수 있어 탐색 비용이 낮다.

### MVP 범위 고정

여러 취미를 지원하지 않는다. 전동공구가 없는 종이·미니블록·간단 조립 키트 중 다음 조건을 만족하는 한 종류만 고른다.

- 10~20개의 명시적 단계가 있다.
- 중간 상태를 직접 촬영할 수 있다.
- 설명서를 합법적으로 데모에 사용할 수 있다.
- 잘못된 안내의 신체 위험이 낮다.

### 3분 데모

1. 설명서 PDF와 중단된 작업의 앞·뒤 사진을 올린다.
2. AI가 가능한 단계 3개와 각각의 보이는 근거를 보여준다.
3. `오른쪽 뒷면의 파란 부품이 보이나요?` 같은 판별 질문을 한다.
4. 사용자가 답하거나 사진을 한 장 더 찍는다.
5. 확정된 단계 번호와 원문 그림을 나란히 보여준다.
6. 필요한 부품과 다음 한 단계만 체크 카드로 제공한다.

### 24시간 반증 실험

- 입력: 같은 키트의 단계별 사진 12장, 모호·가림 사진 5장.
- 기준선: 같은 모델에 설명서와 사진을 한 번에 주는 일반 프롬프트.
- 통과: 단계 top-1 80%, 원문 연결 100%, 모호 입력의 거부/추가사진 요청 80%, 기준선 대비 10%p 개선.
- 즉시 탈락: 정확도 차이 10%p 미만, 근거 없는 단계 생성 1건 이상, 실제 사용자 5건 미확보.

### 17일 MVP

- 입력: 설명서 PDF 1개, 현재 사진 2~3장.
- 핵심 객체: `manual_step`, `visual_state`, `discriminator`, `user_confirmation`, `next_action`.
- 핵심 화면: 설명서 색인 → 사진 비교 → 판별 질문 → 다음 단계 → 재개 체크.
- 이미지 생성, 새 프로젝트 추천, 부품 구매, 여러 취미 지원은 제외한다.

## 예비 1순위 — IDEA-004 HomeDefect Binder

문제 근거만 보면 3개에 들어갈 수 있지만, homepic은 AI 하자 감지·GPS·타임스탬프·문서 OCR·법적 분쟁용 PDF를, Wefect는 누락 증거 검토와 PDF를 이미 제공한다. `[SRC-049]`, `[SRC-050]`

따라서 다음 조건에서만 교체 후보가 된다.

- 한국 공식 절차에 필요한 사진·문자·계약서 사이의 주장-증거 연결을 제공한다.
- 하자 진단, 책임, 승소 가능성은 말하지 않는다.
- 공식 사례 기반 10건에서 누락 증거 재현율 90% 이상을 보인다.
- homepic/Wefect의 공개 결과와 다른 화면을 한 문장으로 설명할 수 있다.

## 24시간 후 선택 규칙

점수 순서로 자동 선정하지 않는다.

1. 세 후보의 사전 등록 통과 기준을 바꾸지 않고 결과를 기록한다.
2. 하나라도 치명 지표를 실패하면 예비 후보와 교체하거나 범위를 더 좁힌다.
3. 둘 이상 통과하면 다음 순서로 최종 한 개를 고른다.
   - 오류를 검출하고 수정할 수 있는가
   - 기준선보다 다른 사용자 결과가 있는가
   - 9월 16일까지 기능 동결이 가능한가
   - 3분 시연에서 AI와 결정론적 검증을 모두 보여주는가
4. 점수 차가 3점 이내면 실제 실험 결과가 원점수보다 우선한다.
