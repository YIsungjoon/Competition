# IDEA-051 비전 모델·개인정보 경로 결정

- 목적: `사진이 묻는 하루`의 첫 실제 사진 실험과 공개 데모에 사용할 모델 경로를 정한다.
- 조사일/시간대: 2026-09-07, Asia/Seoul
- 출처 ID: `SRC-078`~`SRC-081`
- 상태: 공식 기능 확인 완료, 실제 사진 품질·비용 미검증

## 직접 확인한 사실

### OpenAI GPT-5.6 Luna

- `SRC-078`: 이미지 입력과 구조화 출력을 지원한다.
- `SRC-078`: 공식 페이지의 텍스트 토큰 단가는 입력 100만 토큰당 미화 0.20달러, 출력 100만 토큰당 미화 1.20달러다. 이 값만으로 이미지 한 묶음의 비용을 산정하지 않는다.
- `SRC-078`: 무료 API 등급은 지원하지 않는다고 표시돼 있어 유효한 유료 API 프로젝트가 필요하다.
- `SRC-079`: API 입력은 사용자가 명시적으로 동의하지 않는 한 모델 학습에 사용되지 않는다.
- `SRC-079`: 기본 악용 모니터링 로그에는 고객 콘텐츠가 포함될 수 있고 최대 30일 유지될 수 있다. 이미지·파일 입력에는 안전 스캔에 따른 별도 보존 예외도 있다.

### 로컬 Qwen3-VL 4B Instruct

- `SRC-080`, `SRC-081`: 이미지와 텍스트를 입력할 수 있는 4B Instruct 모델이며 Ollama 태그의 파일 크기는 약 3.3GB다.
- 로컬 실행이면 사진을 외부 모델 제공자에게 전송하지 않을 수 있다.
- 모델은 아직 이 프로젝트에서 내려받거나 실행하지 않았다. 한국 생활 사진의 관찰 정확도, 한국어 질문 품질, 응답시간은 모두 미확인이다.

### 현재 실행 환경

- 비밀값을 출력하지 않고 환경변수 이름만 확인했으나, 이번 작업 환경에서는 OpenAI·Google·Gemini 등 클라우드 모델 키 이름을 찾지 못했다.
- RightsLedger에서 사용한 로컬 Ollama는 텍스트·임베딩 모델 경로였으며 Qwen3-VL 다운로드를 대신하지 않는다.

## 해석

| 경로 | 지금 얻는 것 | 지금 감수할 것 | 역할 |
|---|---|---|---|
| GPT-5.6 Luna | 공개 배포가 쉬운 이미지 입력, 근거 객체를 받기 좋은 구조화 출력, 낮은 텍스트 단가 | 유료 키 필요, 실제 이미지 비용·품질 미측정, 기본 로그 최대 30일 가능 | 첫 공개 데모 후보 |
| Qwen3-VL 4B | 사진 외부 전송 없는 로컬 비교, 키 없이 반복 실험 가능 | 3.3GB 다운로드, 로컬 성능 미확인, 지속 공개 링크 운영 부담 | 실패 시 로컬 예비선 |

이는 전 세계 모델 중 GPT-5.6 Luna가 가장 좋다는 판단이 아니다. 제출일까지 한 사람이 시험하고 배포할 수 있는 첫 경로를 정한 것이다.

## 결정

1. 첫 실제 사진 스파이크는 `GPT-5.6 Luna`를 우선 시험한다.
2. 품질을 통과하기 전에는 제품 모델로 확정하지 않는다. 같은 사진 묶음에서 다음 조건을 모두 확인한다.
   - 관찰 사실에 사진 ID가 100% 연결된다.
   - 인물의 신원·관계·감정을 단정한 관찰이 0건이다.
   - 질문 3개 중 2개 이상이 사진 설명을 반복하지 않고 사진 밖 맥락을 묻는다.
   - 사용자가 답하지 않은 사실·감정이 완성 일기에 0건이다.
3. API 호출은 서버에서만 수행하고 브라우저에 키를 전달하지 않는다.
4. Responses API 사용 시 `store: false`를 명시한다. 이것은 애플리케이션 상태 저장을 줄이는 설정이지, 기본 악용 모니터링 로그까지 없다는 약속이 아니다.
5. 브라우저에서 위치정보를 제외하고 사진 크기를 줄인 사본만 전송한다. 원본과 얼굴 벡터를 서버에 저장하지 않는다.
6. 유효한 클라우드 키가 준비되지 않거나 1차 품질 게이트를 통과하지 못하면 그때만 Qwen3-VL 4B를 내려받아 동일 입력으로 비교한다. 두 모델 경로를 동시에 제품 코드로 구현하지 않는다.

## 중단·재검토 조건

- 사진 8장 처리의 실제 비용과 지연이 데모 반복에 부담스러우면 이미지 수·해상도를 먼저 줄인다.
- Luna의 기억 공백 질문이 일반적인 일기 질문과 구분되지 않으면 더 큰 모델을 바로 붙이지 않고 질문 생성 입력 구조를 먼저 점검한다.
- 사용자가 최대 30일 로그 가능성을 받아들이지 않으면 공개 데모를 동의받은 합성 사진으로 제한하고 로컬 처리 경로를 별도 검토한다.
- 다른 유료 멀티모달 API 키가 이미 준비돼 있다면 동일 게이트로 비교한 뒤 공급자 결정을 갱신한다.

- 유효한 서버용 API 키 또는 로컬 3.3GB 모델 다운로드 허용

키 값과 원본 사진은 Git에 기록하지 않는다.
