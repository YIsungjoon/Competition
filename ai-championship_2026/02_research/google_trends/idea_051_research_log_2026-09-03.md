# IDEA-051 사진 기반 회고 검색 신호

- 조사일: 2026-09-03
- 지역/검색: 대한민국, 웹 검색
- 출처: `SRC-022`~`SRC-025`
- 목적: 사용자 아이디어와 직접·인접한 검색 행동을 확인하되 낮은 검색량을 아이디어 부재로 오해하지 않는다.

같은 비교 묶음 안에서 `AI 일기`와 `일기 앱` 신호가 확인됐지만, 절대 검색량이나 시장 규모를 뜻하지 않는다.

### `GT-20`: 인접 기록 행동

`사진 정리`의 상위 관련 검색에는 아이폰 사진 정리, 중복 사진 정리, 사진 정리 프로그램이 나타났다. 이는 사용자가 사진 뭉치를 정리하려는 마찰을 보여주지만 회고·서사 생성 수요를 직접 증명하지는 않는다.

`육아 일기` 연관 검색은 아이돌 콘텐츠에 오염돼 사용 근거에서 제외한다.

### `GT-21`: 회고·라이프로깅 표현

- 회고 일기 0
- 라이프로깅 2
- 추억 기록 0
- 사진으로 일기 2

이 결과는 사용자가 제안한 경험이 아직 널리 통용되는 검색어로 정착하지 않았을 가능성과 실제 수요가 작을 가능성을 모두 포함한다. 검색 자료만으로 둘 중 하나를 선택할 수 없다.

## 해석

### 확인된 것

- AI 일기와 일기 앱이라는 인접 수요가 존재한다.
- 사진 정리에는 비교 묶음 안에서 뚜렷한 관심과 구체적 도구 탐색이 있다.
- 사용자의 정확한 표현인 사진 기반 대화형 회고는 검색어 수준에서 아직 강하게 포착되지 않는다.

### 확인되지 않은 것

- 사진을 올린 뒤 AI 질문에 답하고 싶은 사용자가 충분히 많은지
- 자동 생성 일기보다 질문형 회고에 더 큰 가치를 느끼는지
- 매일 사용할지, 여행·행사 이후에만 사용할지
- 사진을 외부 서버에 올릴 개인정보 부담을 감수하는지

## 판단

Google Trends는 이 아이디어를 강하게 지지하지도 반박하지도 않는다. 직접 검색어 수요가 약하므로 다음 판단 근거는 검색량이 아니라 다음의 사용자 행동 실험이어야 한다.

1. 하루치 사진을 고르는가?
2. 사진별 질문 3개에 답하는가?
3. 완성된 글을 `내 일기 같다`고 느끼는가?
4. 일반 AI 일기와 비교해 다시 사용할 의향이 높아지는가?
